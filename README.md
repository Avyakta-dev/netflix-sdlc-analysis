## Assignment Objective

Analyze the software development lifecycle (SDLC) of Netflix's streaming platform through comparative study of three process models:
- Waterfall Model
- Incremental Development
- Spiral Model

The assignment includes:
- Comparative analysis of process models for Netflix (2007-2011)
- Requirements engineering documentation (functional and non-functional)
- Version control workflow demonstration
- Process model diagrams (Waterfall, Incremental, Spiral)
